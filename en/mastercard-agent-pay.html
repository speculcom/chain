Payments & settlement

Mastercard Agent Pay: a card-network framework for agents

The intersection: Agent Pay is not one API but four card-network pieces — Know Your Agent registration, an Agentic Token uniquely issued per agent, biometric authorisation through Mastercard Payment Passkeys, and Verifiable Intent binding the consumer’s original instruction to the final transaction. Tokens can be scoped by amount, merchant category, time window and purpose, and revoked at any time.
Scope: launched in the US in 2025 and completed live transactions in 2026 across Australia, New Zealand, Singapore, Malaysia, India, Korea, Taiwan and Latin America, with DBS/UOB, hoppa and Santander among participants. Cloudflare’s Web Bot Auth authenticates agent traffic and feeds Agent Pay; the Agent Pay Trust Framework adds identity, fraud and behavioural insight plus an agent probability score for issuers.
Open: it is not on-chain settlement and not a single universal standard; KYA and risk scoring remain with the network/issuer, cross-network interoperability with Visa TAP and Amex ACE is still evolving, and merchant upgrades and geographic coverage are uneven.
